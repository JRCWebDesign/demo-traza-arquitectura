# Recursos visuales

Creación: 23 de octubre de 2026. Herramienta: ImageGen integrado de OpenAI.
Referencia de estilo: `referencias/mockup-traza.png`.

Las imágenes son generadas y conceptuales. No se presentan como fotografías de obras reales.
No se extrajeron fotografías del mockup ni se utilizó su captura como interfaz.

El plano, el recorrido y el favicon son recursos originales del proyecto construidos

con licencia MIT, incluida en `public/assets/ICONS-LICENSE.txt`.
