# Plan de trabajo

## 1. Preparación

Revisar el mockup y el brief. Elegir una base frontend liviana y definir cómo se ejecuta localmente. Mantener el proyecto separado de portfolio-jc. No hay stack impuesto.

## 2. Composición estática

Construir cabecera, apertura, obras, mirada y contacto. Resolver primero tipografía, proporciones, fotografías y plano en escritorio; luego adaptar a móvil. Crear contenido real de interfaz, no una captura incrustada.

## 3. Recursos visuales

Usar imágenes de demostración con derechos de uso claros o generadas para el proyecto. El mockup sirve de referencia, no sustituye las fotografías finales. Dibujar una planta consistente que permita ubicar el recorrido y reservar espacio de lectura.

## 4. Interacción

Hacer funcionar navegación por anclas y presentación de proyectos. Configurar contacto cuando exista un destino real. Incorporar después el trazado progresivo de la línea terracota y las transiciones de imágenes.

## 5. Verificación

- Comparar el resultado con el mockup a un tamaño equivalente.
- Revisar móvil estrecho, tablet y escritorio; evitar desbordamiento horizontal.
- Probar teclado, foco, enlaces, galerías y movimiento reducido.
- Comprobar que la página se entiende sin JavaScript y sin animación.
- Optimizar imágenes y revisar estabilidad del layout y fluidez del scroll.

## Entrega inicial

Una página responsive con el recorrido visual, dos o tres proyectos conceptuales y contacto claramente identificado. Documentar el comando de arranque, las decisiones técnicas y los datos pendientes en README.md. Publicar únicamente cuando el usuario lo solicite.
